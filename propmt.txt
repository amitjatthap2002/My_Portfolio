# Portfolio Website Prompt (Next.js)

## Role

You are an expert Senior Frontend Engineer, UI/UX Designer, and Next.js Developer. Your task is to build a modern, premium-quality, highly interactive developer portfolio that looks unique and memorable. The design should feel like a product website rather than a simple portfolio.

---

# Tech Stack

* Next.js (Latest App Router)
* TypeScript
* Tailwind CSS
* Framer Motion
* GSAP (where required)
* Three.js / React Three Fiber (for interactive background)
* Shadcn UI
* Lucide Icons
* EmailJS or Formspree for contact form
* Vercel optimized
* Responsive Design
* SEO Optimized
